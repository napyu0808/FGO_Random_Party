# FGO ランダムパーティ

FGOのサーヴァントを図鑑番号（実装順）で重複なく6騎引き、パーティ編成画面風に表示する静的なWebページです。
ビルドは不要で、`index.html` を開くだけで動作します。（インターネット接続が必要です）

## 使い方

- **パーティを引く** ボタン、または `Space` — 6騎すべてを引き直します
- **1騎ずつ引く** ボタン — 左の空いている枠から1騎ずつ埋めます（全部埋まっているときは何も起きません）
- **リセット** ボタン — すべての枠を空にします（コストも 0 に戻ります）
- カードをクリック — その枠だけを引き直します（現在のパーティと重複しません）。空の枠をクリックすると、その枠だけ引きます
- カードの上部にレアリティ（★）、下部に名前と図鑑番号が表示されます
- 右下のコストボックスに、6騎のコスト合計が `合計 / 118` で表示されます

### コストの計算

| レアリティ | コスト |
|---|---|
| ★5 | 12 |
| ★4 | 9 |
| ★3 | 7 |
| ★2 | 4 |
| ★1 | 3 |
| マシュ・キリエライト（No.1） | 0 |
| アンリマユ（No.107） | 4 |

## 画像について

サーヴァントの画像はリポジトリに含まれていません。ページを開いた人のブラウザが、[Atlas Academy](https://atlasacademy.io) の画像サーバーから直接読み込みます。
次に引く12騎をあらかじめ裏で読み込んでおくため、ボタンを押すとすぐに表示されます。
（1回に読み込む量は約1MB、サーヴァント1騎あたり約94KBです。）

背景のパーティ編成画面は、ゲーム内のスクリーンショットです（`assets/party-bg.webp`）。

## 公開するとき

GitHub Pagesは各ファイルを約10分間キャッシュします。更新を確実に反映させるため、`index.html` の `?v=` の数字を上げてからコミットしてください。

## 新しいサーヴァントが追加されたら

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-list.ps1
```

Atlas Academyから一覧を取得し直して `data/servants.js` を更新します。更新したファイルをコミットしてください。

## 構成

| パス | 役割 |
|---|---|
| `index.html`, `css/style.css`, `js/main.js` | ページ本体 |
| `data/servants.js` | 図鑑番号・サーヴァントID・レアリティ・日本語名の一覧（`build-list.ps1` が生成） |
| `assets/party-bg.webp` | 背景（ゲーム内スクリーンショット） |
| `tools/build-list.ps1` | 一覧の更新スクリプト |
